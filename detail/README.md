# detail — 상세페이지 이미지 보관함

판매 상세페이지에서 링크로 불러오는 이미지 모음입니다.

- `threads/` — 「알고리즘을 지배하는 텍스트 머신」 시리즈(쓰레드 A to Z 수익화 마스터북 · 쓰레드머신) 상세페이지용

불러오는 주소 형식 (jsDelivr CDN):

```
https://cdn.jsdelivr.net/gh/lawmoses/file@<태그>/detail/threads/<파일명>
```

이미지를 바꾸면 새 태그를 만들어 주소의 태그만 바꿔 주세요(같은 태그는 CDN에 고정 캐시됩니다).
